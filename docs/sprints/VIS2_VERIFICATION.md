## 3. No label describes data the system does not hold

**PASS.**

- `estimated_pickup_date` / `estimated_delivery_date` — zero reads remain (`grep` clean). The keys
  were renamed `scheduled_*` by VIS-1-T05 and the cabinet had not caught up, which is what made the
  date render blank.
- **"Est. delivery" is gone**, and with it all three of its false claims: the word "Est.", its
  placement inside the "YOUR DRIVER" card, and `fmtDeliveryWindow`'s invented "(±2 days)" band. The
  function is deleted, not left unused.
- The replacement states provenance: *"These are the dates Y7 arranged with the carrier; they can
  change — Y7 is a broker and does not control the carrier's schedule."* Verified rendering in the
  walkthrough with `date_source: "y7"`.
- Nothing promises the carrier's own committed dates, which are stored nowhere (VIS-1 §V8) and are
  FUL-1's work.
- `PageMeta title="Dealer Dashboard"` no longer tells an exporter they are a dealer; the browser tab
  read "My Dashboard" in the walkthrough, for an `exporter` account.
- `Billing.jsx` no longer says billing is "for dealer accounts only" when it serves both B2B types.

## 4. Absent values read as their meaning, not as blanks

**PASS**, and verified in both directions, which matters more than either alone.

Before the assignment, the same load row rendered:

```
Carrier not assigned yet
Not priced yet
```

After it:

```
Carrier: BALTIC MOTORS LLC
$440 carrier
```

and **both phrases are gone from the page**. The words appear only while they are true. Both states
are screenshotted in `docs/sprints/vis2-walkthrough/`.

The wording has **one definition** (`src/utils/loadVocabulary.js`) shared by the order list, the
order detail and the B2B dashboard. `grep` confirms the strings appear nowhere else in `src/` except
one comment quoting them.

`$0` is still never used for an unknown price — the formatters return `null` for absent and `"$0"`
only for a real zero. That half of CAB-LOADS T03's reasoning was right and is untouched; the
reversal is documented at the site of the original decision.

Words are suppressed where they would be false: on a **closed** load ("not assigned *yet*" is a
claim about a future that has already happened) and on an order before it is confirmed, via
`carrierExpected()` keyed off the canonical `STATUS_PIPELINE`.
